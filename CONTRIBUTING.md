# Contributing

Thanks for your interest in boxorg!

- **Bugs & ideas**: open an issue. For bugs, include device, OS version and
  steps to reproduce.
- **Pull requests**: welcome for fixes and small improvements. For bigger
  changes, please open an issue first so we can align before you invest time.
- **Code style**: follow [docs/code-conventions.md](docs/code-conventions.md);
  run `pnpm lint` and `npx tsc --noEmit` before submitting.
- **Scope**: boxorg stays local-first, free, and dependency-lean. PRs that add
  accounts, tracking, or cloud services won't be merged.
